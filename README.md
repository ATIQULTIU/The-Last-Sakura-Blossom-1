# 🌸 The Last Sakura Blossom-1

An interactive, ambient web experience featuring dynamic 3D sakura petal simulation, custom synthesized background audio, and dynamic theme switching.

## ✨ Features

- **3D Particle Physics Simulation:** Smooth animation of fluttering sakura petals with dynamic wind vector transformations, turbulence, and rotation.
- **Ambient Background Audio:** Built-in Web Audio API synthesized serene melody ("Sakura Serenade") that plays without requiring external audio files.
- **Interactive Petal Burst:** Clicking or tapping anywhere on the screen triggers a burst of sakura petals from the cursor position.
- **Day / Night Mode Toggle:** Smooth gradient transition to a dark night aesthetic complete with glowing text and updated UI styling.
- **Developer Card & Responsive UI:** Sleek glassmorphism overlay containing project metadata and social links.

## 🚀 How to Run

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Click the **Music Icon** at the top right to start the ambient soundscape.
4. Click anywhere on the screen to trigger interactive petal bursts!
